1.
Give the decimal value of each of the following integer constants.
(a) 077
(b) 0x77
(c) 0XABC

A. (a) 63
(b) 119
(c) 2748

2.
Which of the following are not legal constants in C? Classify each legal constant as either
integer or floating-point.
(a) 010E2
(b) 32.1E+5
(c) 0790
(d) 100_000
(e) 3.978e-2

A. (a) legal as float allows trailing zeroes.
(b) legal
(c) illegal as octal only have digits between 0-7
(d) illegal
(e) legal

3.
Which of the following are not legal types in C?
(a) short unsigned int
(b) short float
(c) long double
(d) unsigned long

A. (b) short float as these modifiers are only applicable on int data types.

4.
If c is a variable of type char, which one of the following statements is illegal?
(a) i += c; /* i has type int */
(b) c = 2 * c - 1;
(c) putchar(c);
(d) printf(c);

A. (d)

5.
Which one of the following is not a legal way to write the number 65? (Assume that the
character set is ASCII.)
(a) 'A'
(b) 0b1000001
(c) 0101
(d) 0x41

A. (b) because as binary represented integers are not allowed.

6.
For each of the following items of data, specify which one of the types char, short, int,
or long is the smallest one guaranteed to be large enough to store the item.
(a) Days in a month
(b) Days in a year
(c) Minutes in a day
(d) Seconds in a day

A. (a) char
(b) short
(c) short
(d) long

codes for ASCII characters.

(d) \t

(b) \12

9.
Suppose that i and j are variables of type int. What is the type of the expression i / j +
'a'?

A. int

10.
Suppose that i is a variable of type int, j is a variable of type long, and k is a variable of
type unsigned int. What is the type of the expression i + (int) j * k?

A. unsigned int

11.
Suppose that i is a variable of type int, f is a variable of type float, and d is a variable
of type double. What is the type of the expression i * f / d?

A. double

12.
Suppose that i is a variable of type int, f is a variable of type float, and d is a variable
of type double. Explain what conversions take place during the execution of the following
statement:
d = i + f;

A. i is first converted to float then added to f, the answer which is of float type is then implicitly cast into double.

13.
Assume that a program contains the following declarations:
char c = '\1';
short s = 2;
int i = -3;
long m = 5;
float f = 6.5f;
double d = 7.5;
Give the value and the type of each expression listed below.
(a) c * i 
(c) f / c 
(e) f - d
(b) s + m 
(d) d / s 
(f) (int) f

A. (a) -3, int
(c) 6.5, float
(e) -1.0, double
(b) 7, long
(d) 3.75, double
(f) 6, int

14.
Does the following statement always compute the fractional part of f correctly (assuming
that f and frac_part are float variables)?
frac_part = f - (int) f;
If not, what’s the problem?

A. Fails in the case of value of f being larger than the largest value int can hold.
